In this chapter, you will create an experimental typography project for the web browser. You will start by previsualizing your page using pencil and paper, then code your design using HTML, CSS, and JavaScript. Start by choosing an important phrase or sentences from one of the texts in the list of manifestos in the callout. Select writing that speaks to you. Our sample concrete poem riffs on Apple’s “Think Different” slogan.

- Preview the [live page](https://criticalwebdesign.github.io/book/02-view-source/2-3/) and [work files](https://github.com/criticalwebdesign/book/tree/main/02-view-source) 
- Start using our [criticalwebdesign/website-template](https://github.com/criticalwebdesign/website-template) 
- [Videos from this chapter](https://criticalwebdesign.github.io/wiki/resources/videos/#chapter-2)
