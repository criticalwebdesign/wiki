In this chapter you will evaluate a prior project using validation and accessibility tools and
examine a design brief for which you will explore common design patterns. Finally, you will
implement code and design choices in answer to our brief that create greater accessibility
for all users, meeting accessibility criteria on an accessibility checklist.
