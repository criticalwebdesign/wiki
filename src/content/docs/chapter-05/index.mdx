In this chapter you will begin by creating and implementing a usability test. 
Then, apply design thinking concepts and our “less is more” critique and revise your layout before coding a responsive web page
that reflects on your findings. You will make the design responsive using Bootstrap and create a working web form with JavaScript that
outputs the score from the System Usability Scale (SUS) survey.

- Preview the [live page](https://criticalwebdesign.github.io/book/05-usability/5-3/) and [work files](https://github.com/criticalwebdesign/book/tree/main/05-usability) 
- Use our [Figma Responsive Templates](https://www.figma.com/community/file/1501679035518799477/cwd-responsive-templates)
- Use our [criticalwebdesign/website-template](https://github.com/criticalwebdesign/website-template)
