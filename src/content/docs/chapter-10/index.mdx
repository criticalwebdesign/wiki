Inspired by We Feel Fine, the modules in this chapter will
lead you to build an interactive site that uses the web to harness the power of participant engagement. 
The technology Harris and Kamvar used (Java Applets) to create and publish the multifaceted interactive
visualizations on [We Feel Fine](http://www.wefeelfine.org/) are no longer supported by web browsers. This prompt is
a modest homage to Harris and Kamvar’s project. In module 1 you will read about how we
planned and designed the prompt and use the structure to imagine your own version of
this project.

Module 2 is an introduction to Leaflet for making interactive maps. In module
3 you’ll learn how databases store user contributions and then follow the full-stack
tutorial here on the wiki to visualize them on a map.

- Preview the [live page](https://big-feelings.vercel.app/) and [work files](https://github.com/omundy/big-feelings) 
- Fork our [Leaflet starter](https://codepen.io/owenmundy/pen/BaEepaV)
- Use our [Figma Responsive Templates](https://www.figma.com/community/file/1501679035518799477/cwd-responsive-templates)
- Use our [criticalwebdesign/website-template](https://github.com/criticalwebdesign/website-template) 
- Explore our collection of [mapping tilesets](https://omundy.github.io/free-tiles/)
- View the [Leaflet Starter Guide](https://leafletjs.com/examples/quick-start/)
