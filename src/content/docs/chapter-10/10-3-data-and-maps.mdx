## Data Persistence

<CustomAside type="excerpt" reference="10.3.1">Data persistence describes the practice of storing and using data beyond the life of a program or a web page. You encounter this every day when you save text to a file on your computer’s hard drive and view it again later, or an app remembers you have logged in because it saved a token inside a cookie, or when you post text or images on the internet for others to see. </CustomAside>

async function main() {

function updateMap(data) {
    removeMarkers();
    for (let i = 0; i < data.length; i++) {
        console.log(data[i]);
        markerLayer[i] = createMarker(data[i]);
    }
}
